## 获取测试图片

由于网络限制，请手动下载以下类型的图片：

1. **灭火器压力表（绿区）** - 指针指向绿色区域
2. **灭火器压力表（红区）** - 指针指向红色区域  
3. **灭火器压力表（黄区）** - 指针指向黄色区域
4. **各种角度和光照条件**

## 建议搜索关键词

- "fire extinguisher pressure gauge green"
- "fire extinguisher pressure gauge red"
- "灭火器压力表 绿区"
- "灭火器压力表 红区"
- "fire extinguisher close up"

## 图片要求

- 格式：JPG/PNG
- 大小：建议 500KB-2MB
- 分辨率：建议 800x600 以上
- 内容：清晰可见的压力表指针

## 使用方式

将下载的图片放入此目录，然后运行测试脚本：

```bash
python test_api.py
```
